    Cover Generator¶

    Build a mixv1 style cover for EmulationStation, in your browser.

    Port packages usually include a cover.png that shows up in EmulationStation and other frontends. This tool builds one for you, using the same mixv1 layout as EmulationStation-ImageMaker.

    Pick your images¶

    Need artwork? SteamGridDB has screenshots, logos, and header images for most games.
